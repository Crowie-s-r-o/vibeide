# VibeiDE workflows and use cases

## Workflows

| Workflow | Use it for | Read more |
| --- | --- | --- |
| Execute | One bounded task through Codex, Claude Code or OpenCode when project capacity is available | [AI agent task queue](https://vibeide.dev/use-cases/ai-agent-task-queue/) |
| Plan council | A decision that needs challenge: one provider plans, the other reviews, the author revises | [Plan council](https://vibeide.dev/use-cases/plan-council/) |
| Turbo | A larger objective with dependencies: a fresh planner builds the graph, a separate executor implements it | [Product tour](https://vibeide.dev/features/) |
| Standup | Short notes from the work completed on a chosen day | [Product tour](https://vibeide.dev/features/) |

## Use cases

- [Parallel AI coding agents](https://vibeide.dev/use-cases/parallel-ai-coding-agents/): concurrency, independent writes and review.
- [Claude Code rate limits](https://vibeide.dev/use-cases/claude-code-rate-limit/): provider-reported usage and reset countdowns.
- [Resume a Claude Code session](https://vibeide.dev/resume/claude-code-session/): return to the original request and native conversation.
- [Free AI coding models](https://vibeide.dev/use-cases/free-ai-coding-models/): what is free in OpenCode Zen and OpenRouter, and how to queue OpenCode work on a free model.
- [Team and Company mode](https://vibeide.dev/teams/): human seats, manager visibility and sharing boundaries.

## Who uses it

- [Indie hackers](https://vibeide.dev/for/indie-hackers/): side-project queues, provider limits and finished work in one place.
- [Freelancers](https://vibeide.dev/for/freelancers/): client repositories with project queues and dated Standup summaries.
- [Founders](https://vibeide.dev/for/founders/): from an idea to a reviewed implementation with Plan council.
- [Agencies](https://vibeide.dev/for/agencies/): one workspace for several client repositories.

## Limits worth knowing

- Project queues are not filesystem sandboxes. Choose separate Git worktrees or sequence overlapping changes.
- More process slots do not increase your provider allowance.
- Opening a finished result acknowledges it; it does not approve the code.
- Mobile control needs the paired computer to stay awake, connected and running VibeiDE.
